# 📚 Flashcard App – Veda Technology Task 28

## 📌 Project Overview
The Flashcard App is a simple and interactive web application developed using HTML5, CSS3, and JavaScript. It helps users learn and remember concepts through question-and-answer flashcards.

Users can flip cards to reveal answers and navigate between cards using Previous and Next buttons.

## 🎯 Objectives
- Practice CSS 3D transforms.
- Understand JavaScript arrays and objects.
- Implement card flipping animations.
- Manage card navigation using JavaScript.
- Display learning progress.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## ✨ Features
- 10 predefined flashcards.
- Interactive 3D card flip animation.
- Next and Previous navigation.
- Progress bar indicator.
- Shuffle cards functionality.
- Reset deck option.
- Responsive design for mobile and desktop.
- Keyboard navigation using arrow keys.

   ```bash
   git clone https://github.com/mullapatinagalaxmi-2005/veda-task-28-flashcard-app.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Click on a flashcard to reveal its answer.

## 💡 How It Works
- Flashcard questions and answers are stored in a JavaScript array of objects.
- CSS `transform: rotateY()` creates the 3D flip animation.
- JavaScript tracks the current card index.
- Previous and Next buttons navigate through the deck.
- A progress bar shows the current card position.
- Shuffle randomly changes the card order.
